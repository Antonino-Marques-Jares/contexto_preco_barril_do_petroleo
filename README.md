# contexto_preco_barril_do_petroleo
Informações de contexto relacionado ao aumento no preço do barril de petróleo

![Eventos](guerra_naval.webp)

# Passo 1
Clone o projeto execute 'pip install -r requirements.txt' para instalar as bibliotecas

# Passo 2
Adicione pasta etl no projeto github

# Passo 3
Verifique se tem acesso a internet e 
execute o etl_atualizar_contexto_preco_barril_do_petroleo_no_site.py 
O programa vai gerar arquivo json atualizado a partir da pagina 
https://www.areadetrampo.com.br/fatores-geopoliticos-e-o-preco-do-petroleo/

# Passo 4
O programa vai gerar o json na pasta etl

# Passo 5
Caso queira apenas acessar o json
https://www.areadetrampo.com.br/gestao_dados/contexto_preco_barril_do_petroleo.json
